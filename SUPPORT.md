## 🛠 Feature Breakdown

### Feature 1 — Recon
Detect infection signs: fans at idle, high CPU, new toolbars, unknown processes.

### Feature 2 — Process Hunt
Find hidden, unsigned, or impersonating processes.

### Feature 3 — Persistence Purge
Remove scheduled tasks, services, WMI subscriptions, and registry run keys.

### Feature 4 — Browser Clean
Strip malicious extensions, hijacked search, and changed DNS.

### Feature 5 — Network Check
Spot C2 traffic, unusual outbound connections, and rogue DNS.

### Feature 6 — Post-Clean Hardening
Rotate passwords, enable 2FA, block autorun, and lock down UAC.
